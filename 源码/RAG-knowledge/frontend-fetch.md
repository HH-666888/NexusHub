# 前端页面

## 用 fetch 调真实接口
页面数据必须来自后端接口，使用 fetch 请求，处理 loading、成功、空态、失败四种状态。不能只用 localStorage 假装持久化，也不能把示例数据写死在页面里。

## 空态要具体
空列表时显示“还没有数据”以及下一步动作，不要只显示一个空白区域。空态不是错误态，不要把没有数据当成请求失败。

## 错误要能恢复
请求失败时显示可读提示，并提供重试按钮。不要 alert 后把页面留在半加载状态，也不要把后端错误原文直接铺在页面上。

## 交互反馈要及时
提交按钮点击后立即禁用并显示进行中，成功后恢复并更新列表，失败后恢复并提示原因。删除操作要有二次确认，确认后乐观更新或重新拉取列表。

## 不要引入不必要的依赖
单页工具优先使用原生 DOM 和 fetch，减少构建和加载成本。需要编辑器、图表等重能力时再按需引入，并确保只在对应页面加载。
