# 接口契约

## 入口变量必须叫 app
后端入口文件必须定义 app = FastAPI()，变量名不能改。装配阶段会按这个变量导入应用；改名会导致启动失败。

## 路由与状态码
查询用 GET，创建用 POST，更新用 PATCH 或 PUT，删除用 DELETE。创建成功返回 201，查询成功返回 200，参数错误返回 400 或 422，资源不存在返回 404，冲突返回 409。不要所有情况都返回 200。

## 请求与响应结构稳定
请求体字段名、响应字段名一旦定下就不要随意改。列表接口统一返回对象，例如 items 数组加 total，不要有时返回数组、有时返回对象。字段缺失要让调用方明确知道，不要用空字符串冒充。

## 错误响应要可读
错误响应至少包含 detail 字段，说明是哪一类错误。不要返回堆栈或数据库原始错误给前端；日志里保留细节，响应里给用户能理解的信息。

## 前端只依赖契约
前端页面只通过 fetch 调接口，不直接读数据库、不把数据写死在页面里。接口没准备好时，页面显示空态或错误态，不要用假数据填充。
