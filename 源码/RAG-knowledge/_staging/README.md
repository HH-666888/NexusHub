# RAG 知识库草稿区

这里放还没整理好的原始材料：网页摘录、笔记、案例、术语解释、竞品分析、用户反馈。

**这个目录不参与检索。** 后端只扫描 `RAG-knowledge/` 根目录下的 `.md`，不会扫描 `_staging/`。

整理好一篇之后，把它移动到上一级目录，命名为 `01-主题.md`、`02-主题.md`，然后在后台执行一次重建索引，片段才会进入数据库、参与检索。

约定：

- 一个文件只讲一个主题
- 一级标题写主题名，二级标题写可以独立检索的小节
- 不写密钥、手机号、真实用户隐私
- 没验证过的数字标注“待核实”
- 从草稿转正式文档时，不要直接复制整篇网页，要改写成自己的判断
