## 设计主张

**一句话：白纸、蓝笔、圆角，像一件现代工具，而不是一块大屏。**

参考你给的四张图（欢迎页 / 设置页 / 画布 / 登录页），只取视觉体系，页面结构按功能重排：

- 白底 + 极淡径向渐变；卡片 12–20px 圆角、1px 浅描边；阴影只负责"浮起"，不做戏剧感
- 一个主色 `#2563eb`：主按钮、选中态、进度、链接都用它；状态色只留给「通过 / 待确认 / 未通过」
- 全部无衬线；标题 700–800 字重、`-0.02em ~ -0.03em` 字距，正文 13.5–16.5px
- 图标统一 1.6px 描边、24 的网格里画，尺寸只在 17/19/23/25 四档
- 两套主题只换值不换结构：`<html data-theme="light|dark">`

## 两种外观：素面 / 玻璃

同一份 HTML 两种皮肤，靠 URL 参数切换，便于并排比较：

| 外观 | 怎么打开 | 性格 | 适合 |
|---|---|---|---|
| **素面**（默认） | `…/welcome.html` | 白底、细边、克制的阴影 | 长时间使用、投屏、打印式清晰 |
| **玻璃态** | `…/welcome.html?style=glass` | 背景有蓝青光晕、卡片半透模糊、按钮发光 | 首屏展示、演示视频、让人"哇"一下 |

深色同理：`?theme=dark&style=glass`。

玻璃态的实现原则（`system/glass.css`）：

1. **背景必须先有颜色** —— 没有色块就没有"透"可言，所以加了四团模糊径向渐变（蓝 / 青 / 浅蓝 / 靛）；
2. **卡片半透 + backdrop-filter** —— `rgba(255,255,255,.88→.46)` 斜向渐变，内描边 1px 白色做高光，外侧只留一层柔影；
3. **光只落在会被点的东西上** —— 主按钮、当前工序、进度条才有发光；正文和表格一律不发光；
4. **工作区要安静** —— 画布区额外压一层白纱，否则色块透上来会干扰读节点。

## 五个页面各自解决什么

| 页面 | 谁在看 | 要回答的问题 | 关键元素 |
|---|---|---|---|
| **welcome** | 第一次来的人 | 这是干什么的？靠不靠谱？ | 一句话标题、需求输入 + 生成、六道工序卡、三条能力（可观测 / 可预算 / 可干预） |
| **login** | 老用户 | 怎么进去？ | 居中卡片、账号 + 密码、第三方登录、"还没有账号" |
| **projects** | 登录后 | 我造过什么？哪个在等我？ | 顶部一句新需求、四个筛选、六张状态卡（新建 / 运行中 / 待你确认 / 验收 6/6 / 验收 4/4 / 验收 4/6） |
| **canvas** | 正在等结果的人 | 现在到哪一步？花了多少？ | 左：运行历史；中：六节点流程图 + 三方向子任务 + 终端；右：事件流 / 本轮预算 / 工序详情 |
| **settings** | 要换模型或控成本的人 | 用谁的大脑、花多少、长什么样 | 模型提供商三选一、API Key、决策/执行模型、两个预算滑杆、两套主题预览、底部保存条 |

## 文案（全部重写）

首页那句话是整站的地基。参考图说"输入一句话，生成一个可运行的软件"，我保留同样的直白，只把承诺说得更实：

- 标题：**输入一句话，生成一个可运行的软件**
- 副标：Nexus 把需求拆成六道工序，由 AI 自主构建、集成并验收，最后交给你一个能打开、能点、数据存得住的完整软件。
- 输入框：描述你的软件需求，例如：做一个番茄钟网页应用
- 三块能力：**可观测**（每一步都在你眼前）/ **可预算**（签下需求前就看到预估花费）/ **可干预**（拿不准的地方它先停下来问你）

其余页面的文案原则：写"会发生什么"，不写形容词；状态用「验收 6/6」「待你确认」这种能对账的说法。
