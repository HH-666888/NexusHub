## 这一版的设计主张

**它是一间工厂，不是聊天框。**

老首页把最强的位置给了一个大输入框，看起来像又一个 AI 聊天产品；可这个产品真正特别的地方是
"六个工序 → 真跑起来的产物 → 验收报告"。所以新版把首页当成**一张工单（work order）**来设计：

- 左边竖向标尺 = 六道工序，永远在那儿，随时回答"现在到哪一道了"
- 中间是工单纸：编号、字段、预算、签发 —— 提交前就把"会发生什么"写清楚
- 右边是深色控制台 = 机器那一侧：此刻在造什么、今天产出多少、预算水位、最近活动
- 下边是成品架：每件产物一张卡，带状态印章与动作（预览 / 下载 / 回放）

视觉语言：**制图纸 + 工单 + 印章**。纸（人看的东西）与石墨（机器跑的东西）分工明确，
一眼能分清"我填的"和"它在动的"。

### 颜色

| 变量 | 值 | 用途 |
|---|---|---|
| `--paper` | `#f2efe6` | 制图纸底 |
| `--paper-hi` | `#fbfaf4` | 工单纸、卡片 |
| `--ink` | `#16181c` | 石墨：正文、边框、主按钮 |
| `--red` | `#c1371f` | 朱红：工单编号、印章、当前工序、主按钮悬停 |
| `--green` | `#1f7a4d` | 验收通过 |
| `--blue` | `#1f43b8` | 次级链接 |

只有一个强调色（朱红），它只在"需要你注意"的地方出现：当前工序、印章、签发。

### 字体

- 标题：衬线（宋体系）—— 像图签上的标题字，与"造东西"的分量相称
- 标签 / 数字：等宽 —— 工单号、花费、时间都是数据，等宽才对得齐
- 正文：无衬线 —— 中文正文用衬线会糊，正文一律无衬线

## 功能对照（这一版覆盖了什么）

| 功能 | 在老界面上 | 在这一版上 |
|---|---|---|
| 一句话需求 | 居中大输入框 | 工单字段 ①，带"换个角度试试"样例 |
| 产物形态 | 顶部三个胶囊 | 字段 ②，三个卡片（网页应用 / 小工具 / 小游戏），带一句代价说明 |
| 预算上限 | 全局设置里 | 字段 ③，签发前就能定，滑块 + 数字 |
| 签发前预期 | 没有 | "6 道工序 · 4—6 分钟 · ¥0.3—0.8 · 可能问你 1—3 次" |
| 累计花费 | 顶栏一个数 | 顶栏 + 控制台"预算水位"（含上限） |
| 我的项目 | 三张空缩略卡 | 成品架 6 张，且**区分五种状态**：进行中 / 待你拍板 / 已完成 / 未通过 / 新建 |
| 工序进度 | 三张营销卡 | 左侧常驻标尺，标出"当前工序" |
| 此刻在跑什么 | 没有 | 控制台第一块 |
| 最近活动 | 没有 | 控制台底部时间线 |

## 还没做的（等确认方向再往下）

- 悬停 / 聚焦 / 提交中的过渡态（静态稿只能示意）
- 空状态：一条工单都没有时，成品架该长什么样
- 窄屏（< 1100px）折叠规则：左标尺收成横条、右控制台移到工单下方
- 深色主题：制图纸底是否可以整套翻黑（现在只有顶栏与右栏是深的）
- 首页之后：产线（运行中）、成品架（全部）、工作台（单条运行）三页
