# 十六、三个验收场景的逐帧走查

> 这一份用“习惯打卡”完整走一遍，标出每个事件、每段界面变化、每个验收点。
> 另外两个场景（投票、记账）只列差异点。

## 场景 A：习惯打卡

### 输入

```
做一个习惯打卡，能每天打卡、看连续天数
```

### 第 0 秒：创建

```
POST /api/v1/runs { "prompt": "做一个习惯打卡，能每天打卡、看连续天数" }
→ 201 { "id": "r_8f2c..." }

DB: runs(status=running, stage=plan, total_cost_cny=0)
事件:
  phase(spec, "需求分析")
```

界面：项目页跳转 → 工作台 → 顶栏“运行中 · 第 1/6 道”，树只有根节点。

### 第 1–8 秒：需求分析

```
task(created, task-plan-3f2a: "澄清需求边界")
task(created, task-plan-9c1b: "写验收标准")
task(started, task-plan-3f2a)
reasoning("先确认打卡粒度：一天一次还是多次？")
task(done, task-plan-3f2a, note="边界已定")
task(started, task-plan-9c1b)
spec({
  goal: "记录每天的习惯完成情况，并展示连续天数",
  acceptance: [
    "能创建一个习惯",
    "每天能打卡一次，重复打卡不重复计数",
    "连续天数按自然日计算",
    "刷新页面后数据还在"
  ],
  questions: [
    { id:"q1", type:"single", text:"打卡一天一次还是多次？", options:["一天一次","可以多次"], default:"一天一次" },
    { id:"q2", type:"single", text:"连续天数按自然日还是 24 小时？", options:["自然日","24 小时"], default:"自然日" },
    { id:"q3", type:"single", text:"需要按习惯分类吗？", options:["需要","不需要"], default:"不需要" },
    { id:"q4", type:"text",   text:"时区按哪个？", default:"本地时区" },
    { id:"q5", type:"text",   text:"数据保留多久？", default:"永久" }
  ]
})
task(done, task-plan-9c1b, note="4 条验收标准")
phase(awaiting, "等待确认")
cost(0.012)
```

界面：

- 第 1 道卡片“进行中” → 副标“正在理解需求”
- 树长出 2 个任务节点
- 思考条滚动
- **门禁弹窗**：问题 + 两个选项

用户一轮答完 5 个问题 → `POST /answers`（带 round=1）→ `gate.answered` → `phase(spec)` 继续。
答案进 `ctx.answers`，后面的设计/开发不再重复问同样的事。

### 第 9–18 秒：架构设计

```
task(created ×2: "划模块边界" / "定数据流与页面")
task(started 划模块边界)
arch({
  modules: [
    {id:"db", files:["db/schema.sql"], covers:["a2","a3"]},
    {id:"api", files:["api/main.py"], covers:["a1","a2"]},
    {id:"web", files:["web/index.html"], covers:["a4"]}
  ],
  dependencies: [{from:"web",to:"api"},{from:"api",to:"db"}],
  run: {entry:"api/main.py", port:8000}
})
task(done, note="3 个模块")
task(started 定数据流) → task(done, note="页面 → 接口 → 表")
check({results:[], summary:{passed:4,total:4}})
cost(0.018)
```

界面：第 2 道卡片出现，3 个模块节点逐个长出，连线画出。

### 第 19–70 秒：自主开发

```
task(created ×3: 写数据库 / 写后端接口 / 写前端页面)
task(started 写数据库)
file(db/schema.sql, delta=..., lines=1..12)
task(done 写数据库, ms=4200, result={lines:12})
task(started 写后端接口 / 写前端页面)   ← 并行
file(api/main.py, ...)  file(web/index.html, ...)
task(done 写后端接口, ms=15600, result={lines:48})
task(done 写前端页面, ms=13100, result={lines:52})
cost(0.061)
```

界面：

- 同一时刻只有一个任务节点转蓝，完成后下一个才开始
- 代码区三个标签，逐行输出，行数从 9 → 12 → 48
- 顶栏成本从 ¥0.03 涨到 ¥0.09

### 第 71–85 秒：集成装配

```
task(created, "接线与配置")
task(started) → text("入口、路由、配置一次接好")
file(app.py, ...)         # 新增入口
task(done, note="入口已通")
```

界面：第 4 道卡片；代码区多一个 `app.py` 标签。

### 第 86–120 秒：自动测试

```
task(created ×4: 能创建习惯 / 打卡一次 / 连续天数 / 刷新还在)
task(started 能创建习惯) → check(pass) → task(done)
...
task(failed 连续天数, reason="期望 3，实际 2")
check({passed:3,total:4,failed:1})
phase(building, "回环修复")
task(created, "修复：连续天数")
file(api/main.py, replace=true, ...)
task(done, note="改完")
phase(checking, "复测")
task(created, "复测：连续天数") → task(done, note="通过")
check({passed:4,total:4})
```

界面：

- 第 5 道卡片，4 个用例节点
- 第 3 个变红，点开看到“期望 3，实际 2”
- 第 3 道重新亮起，出现“修复：连续天数”节点
- 红节点变绿

### 第 121–135 秒：验收交付

```
task(created, "打包产物")
verdict(layers: db 2/2, api 3/3, ui 1/1)
artifact(index.html) artifact(spec.json) artifact(manifest.json)
task(done, note="可预览")
phase(done)
runs.status = done
```

界面：6/6 全部完成；预览 tab 打开 `http://127.0.0.1:50123/`；验收 tab 三层全绿。

## 场景 B：投票（差异点）

| 阶段 | 与 A 的差异 |
|---|---|
| spec | 验收标准含“一人一票”“百分比正确” |
| arch | 表 `polls`、`votes`；接口 3 个；页面 1 个 |
| build | 文件数 3，代码含 `poll`/`vote` |
| test | 用例含“重复投票返回 409”“百分比 50%” |
| 失败点 | 大概率在“重复投票”去重逻辑 |

## 场景 C：记账（带分类）

| 阶段 | 差异 |
|---|---|
| spec | 验收标准含“按分类汇总” |
| arch | `entries` 表带 `category`；接口含 `/api/summary?by=category` |
| test | 用例：记三笔 → 分类合计 = 总额 |
| 失败点 | 汇总 SQL 的 GROUP BY 或浮点比较 |

## 三个场景的公共断言（脚本化）

```python
assert run.status == "done"
assert run.stage == "deliver"
assert len(tasks) >= 10
assert all(t["state"] == "done" for t in tasks if t["kind"] != "test" or t.get("retest"))
assert len(artifacts) >= 3
assert run.total_cost_cny > 0
assert abs(sum(cost_records) - run.total_cost_cny) < 1e-4
assert preview_status == 200
assert any("连续" in page or "投票" in page or "分类" in page for page in pages)
```
