# 二十、内容真实性红线（v2 专用）

> 适用于 `web-v2/` 与 `backend/app/v2/` 的每一行。
> 一句话：**界面上的每个字、每个数、每段代码，要么来自真实数据，要么明确是占位符；不允许“看起来像真的假数据”。**

---

## 1. 什么叫“假内容”

| 类型 | 例子 | 为什么不行 |
|---|---|---|
| 假数据 | 项目页写死“13 项”、进度写死 46%、预算写死 ¥5.87 | 用户会以为是真实统计 |
| 假状态 | 没有事件却显示“已完成 4/4” | 状态必须有事件来源 |
| 假代码 | 代码区塞一段示例代码当产物 | 产物必须来自模型/文件 |
| 假成本 | 固定 0.14、固定“9 次调用” | 成本必须来自 cost_records |
| 假时间 | 写死“11-05 22:02” | 时间必须来自 created_at |
| 假用户 | 头像写死 “demo” | 必须来自 me() |
| 死控件 | 按钮点了没反应 | 要么接真实逻辑，要么不显示 |
| 演示分支 | 没后端就播演示时间线 | v2 不允许演示态，只允许空态/错误态 |

## 2. 什么叫“占位符”（允许）

占位符的特征：**一眼能看出“这里还没有内容”，且不冒充真实值。**

| 场景 | 正确占位 | 错误做法 |
|---|---|---|
| 没有运行记录 | 空态插画 + “还没有运行，输入一句话开始” | 塞三张假卡片 |
| 数值未知 | `—`（破折号） | `46%` |
| 列表为空 | “暂无任务” | 列出假任务 |
| 代码未选择 | “选择一个文件查看内容” | 预填示例代码 |
| 加载中 | 骨架屏 / “加载中…” | 先显示假数据再替换 |
| 头像 | 用户名首字母 / 默认人形图标 | 写死 “demo” |
| 时间未知 | `—` | 编一个时间 |
| 统计为 0 | `0`（真实为零） | 编一个非零数 |

## 3. 空态、错误态、加载态（三种合法状态）

每个数据区域必须能回答：没数据时显示什么？

```
加载中  → 骨架屏或“加载中…”
空      → 空态文案 + 引导动作
错误    → 错误原因 + 重试按钮（真实错误信息，不吞掉）
有数据  → 真实渲染
```

不允许出现第四种状态：“假装有数据”。

## 4. 后端红线

- 不允许 `demo.py` 式的模板生成器进入 v2
- 不允许写死 `cost`、`verdict`、`check` 结果
- 不允许在接口里返回“示例运行”
- 模型失败 → 返回失败；不要伪造成功
- 测试夹具（fixtures）可以造假数据，但**只在测试里**，不得进接口返回值
- 录制回放（cassette）是真实录制的，事件里必须标 `replay: true`

## 5. 允许的“典型占位符”清单

统一用下面这些词，不要各写各的：

```
—            数值/时间未知
暂无          列表为空（“暂无运行”“暂无任务”）
加载中…        请求进行中
还没有…        首次使用引导（“还没有运行，输入一句话开始”）
重试          错误态按钮
```

## 6. 代码审查清单（每次提交前 grep）

```powershell
# 1) 写死的数字
Select-String -Path "web-v2\**\*.js","web-v2\**\*.html" -Pattern '13 项|46%|5\.87|¥1\.42|14\.13'

# 2) 演示残留
Select-String -Path "web-v2" -Pattern 'demo|演示|示例数据' -Recurse

# 3) 写死的成本/时间
Select-String -Path "backend\app\v2" -Pattern '0\.14|0\.02|0\.03|0\.09' -Recurse

# 4) 死控件（人工）
# 每个 button 要么有 handler，要么不渲染
```

## 7. 与旧站的关系

- 旧站 `/` 保留演示，不受本红线约束（它是兜底）
- 新站 `/v2` 一条都不许
- 两站共用数据库时，v2 列表只显示自己的 `r2-` 运行，不混入旧演示数据

## 8. 验收

- [ ] 断开后端打开 `/v2/`：显示错误态，不是假数据
- [ ] 新账号登录：项目页是空态，不是三张卡
- [ ] 未运行的任务点：显示“—”或“等待”，不是伪造进度
- [ ] 代码区没选文件：提示选择，不是示例代码
- [ ] 全站搜索 `demo`：v2 目录 0 命中
