## 1. 模型客户端（`app/ai/model/client.py`）

### 1.1 接口

```python
class ModelClient:
    def complete(self, *, messages, model, max_tokens=800,
                 temperature=0.2, json_mode=False) -> ModelReply: ...

@dataclass
class ModelReply:
    content: str
    model: str
    prompt_tokens: int
    completion_tokens: int
    latency_ms: int
    raw: dict
```

### 1.2 配置

```
DEEPSEEK_API_KEY=...          # .env，不入库
DEEPSEEK_BASE_URL=https://api.deepseek.com
MODEL_DECIDE=deepseek-chat    # plan / design
MODEL_BUILD=deepseek-chat     # build / assemble / test
```

> 设置页里已存 `modelDecide/modelBuild`，重构后**真的读它**：`resolve_model(stage)`。

### 1.3 调用实现

- 使用 `httpx.Client(timeout=60)`（依赖已装）
- `json_mode=True` 时传 `response_format={"type":"json_object"}`
- 失败重试：网络错/429 → 退避 1s/3s，最多 2 次；4xx（除 429）不重试
- 流式：本轮不做 token 级流式；按任务完成后一次写文件（前端仍逐块展示）

### 1.4 结构化输出

```
prompt 里给 JSON schema 摘要 + 一句“只输出 JSON”
→ 解析失败：把原文与错误发回模型，要求“只修复 JSON”，重试 1 次
→ 仍失败：抛 ModelFormatError，由任务层记为 failed（模型错）
```

### 1.5 录制回放（测试/离线用）

```
RECORD_MODE=off | record | replay
record: 每次调用把 (hash(prompt), reply) 写 data/cassettes/<hash>.json
replay: 命中则直接返回，未命中抛错
```

用途：集成测试不花钱；现场无网时用录制跑完整流程。

## 2. 成本（`app/ai/cost/`）

### 2.1 单价表（唯一事实来源）

```python
PRICES = {
    "deepseek-chat": {
        "input":  {"peak": 2.0, "offpeak": 1.0},   # 元/百万 token
        "output": {"peak": 8.0, "offpeak": 4.0},
    },
}
```

峰谷按北京时间：峰时 08:30–00:30，其余为谷时（具体以官方为准，集中在 `pricing.py` 改一处）。

### 2.2 记账

每次调用**必须**写一条 `cost_records`：

```python
cost = (pt * in_price + ct * out_price) / 1_000_000
db.add(CostRecord(run_id=..., stage=..., model=..., prompt_tokens=pt,
                  completion_tokens=ct, price_tier=tier,
                  cost_cny=cost, latency_ms=..., created_at=now_ms()))
runs.total_cost_cny += cost
emit(usage(...)); emit(cost(...))
```

### 2.3 闸门

```python
before_call: 估算 = max_tokens * out_price; 若 已花 + 估算 > budgetPerRun → BudgetExceeded
after_call:  累计 > budgetPerRun → 暂停运行 + error 事件
```

## 3. 工具层（`app/tools/`）

### 3.1 文件工具

```python
read_file(path)  -> str          # 只允许在工作区内
write_file(path, content) -> None
list_dir(path)   -> list[str]
```

安全：
- 路径 `resolve()` 后必须 `startswith(workspace_root)`
- 单文件 ≤ 512KB；总工作区 ≤ 50MB
- 不允许写 `.env`、`..`、绝对路径

### 3.2 命令工具

```python
run_command(cmd: list[str], timeout=30) -> CommandResult
```

白名单（只允许这些可执行文件）：

```
python, python3, pip（只读查询）, ls, dir, cat, type, echo
```

禁止：`rm`、`del`、`powershell`、`cmd /c`、`curl`、`wget`、任何带 `|` `>` `&` 的字符串。
实现：`subprocess.run(cmd, shell=False, timeout=timeout, capture_output=True)`，输出截断 8KB。

### 3.3 预览工具

```python
start_preview(entry, port) -> PreviewHandle
stop_preview(handle)
wait_http(url, timeout) -> bool
```

内部用 `runtime` 模块（见 §4），不重复实现。

### 3.4 工具调用事件

每次工具调用发 `tool` 事件：

```json
{"kind":"tool","name":"write_file","args":{"path":"api/main.py"},"ok":true,"latencyMs":12}
```

前端可选展示，不阻塞。

## 4. 运行时（`app/features/runtime`）

### 4.1 抽象

```python
class RuntimeBackend(Protocol):
    def start(self, run_id, files_dir, entry, port) -> Handle
    def stop(self, run_id) -> None
    def status(self, run_id) -> str
```

两个实现：

| 实现 | 说明 |
|---|---|
| `ProcessBackend` | 本机 `Popen`，正式使用 |
| `DockerBackend` | 后续服务器用，接口不变 |

### 4.2 进程后端细节

- 工作区：`D:\nexus-workspace\<run_id>`（可用 `RUNTIME_WORKSPACE_DIR` 覆盖）
- 端口：50000 起，`socket.bind` 探测空闲
- 启动：`[python, entry]`，`cwd=files_dir`，`env={**os.environ, "PORT": str(port)}`
- 健康：每 300ms 请求 `/`，15s 超时
- 停止：`terminate()` → 3s 后 `kill()`
- 回收：`reap_stale()` 在列表接口调用（已有）

### 4.3 与 Docker 的等价性

| 能力 | 进程 | Docker |
|---|---|---|
| 独立工作区 | ✅ 目录 | ✅ 挂载 |
| 端口隔离 | ✅ 动态端口 | ✅ 映射 |
| 资源限制 | ⚠️ 无（单机演示可接受） | ✅ CPU/内存 |
| 只读根 | ❌ | ✅ |
| 出网限制 | ❌ | ✅ |

文档里必须如实标注：本机为进程隔离，服务器版本切 Docker；**接口与产物不变**。

## 6. 失败与降级总表

| 组件 | 失败 | 降级 |
|---|---|---|
| 模型 | 超时/429 | 退避重试 2 次；仍失败 → 任务 failed |
| 模型 | JSON 不合法 | 修复重试 1 次；仍失败 → 降级文本解析 |
| 工具 | 命令超时 | 杀进程，任务 failed（环境错） |
| 运行时 | 端口占用 | 换端口重试 1 次 |
| 运行时 | 起不来 | 返回静态产物预览（artifacts 里的 HTML） |
| 检索 | 无命中 | 跳过，不阻塞 |
| 网络 | 全断 | `RECORD_MODE=replay` 跑录制 |
