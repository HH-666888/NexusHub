# 八、前端：从事件到界面

> 约束：**视觉不变**。只增加三类东西：门禁弹窗、证据字段、任务定位。
> 现有文件结构、类名、样式体系全部沿用。

---

## 1. 数据流（不变）

```
SSE /api/v1/runs/{id}/stream
  → live.js 的 apply(kind, payload, at)
    → window.__wb 的桥方法
      → 页面 DOM
```

重构只改“事件内容”，不改这条管道。

---

## 2. 事件 → 界面的精确映射

| 事件 | 调用的桥方法 | 页面变化 |
|---|---|---|
| `phase` | `setStage(index)` | 左侧六道状态、顶栏“第 N/6 道” |
| `task.created` | `addTask(task)` | 树长节点、侧栏加行、任务数+1 |
| `task.started` | `addTask({state:"running", ms?})` | 节点转蓝、侧栏“进行中” |
| `task.done` | `addTask({state:"done", ms, result})` | 节点转绿、进度前进 |
| `task.failed` | `addTask({state:"failed", reason})` | 节点标红、侧栏“失败” |
| `file` | `feedFile(path, lang, delta, done, replace)` | 代码逐行、标签状态变化 |
| `spec` | `setEvent("需求分析完成")` | 第 1 道副标“N 条验收标准” |
| `arch` | `setEvent(...)` | 第 2 道副标“N 个模块” |
| `check` | `setEvent("自测 x/y")` | 第 5 道用例节点 |
| `verdict` | `setVerdict(layers)` | 验收 tab |
| `cost` | `setCost(total)` | 顶栏 ¥ |
| `usage` | `addCall()` | 调用次数 |
| `error` | `setStatus("failed")` + 事件条 | 顶部状态 |

## 3. 需要新增/增强的三处

### 3.1 门禁弹窗（新增）

触发：收到 `phase(awaiting)` 且 `payload.gate` 存在。

结构（沿用现有 modal 风格）：

```
┌──────────────────────────────┐
│ 需要你确认一件事              │
│                              │
│ Q1 打卡是否需要按习惯分类？    │
│   ( ) 需要   ( ) 不需要       │
│                              │
│ [按你的理解继续]  [提交]      │
└──────────────────────────────┘
```

提交：`POST /api/v1/runs/{id}/answers`，body：

```json
{ "answers": [{ "id": "q1", "value": "需要" }], "auto": false }
```

超时（前端 5 分钟）自动提交 `auto: true`。

### 3.2 证据卡（增强，不改布局）

现有字段：标题、状态、耗时、产物、说明/原因。
新增两行：

```
重试    第 2 次
结果    3 个文件 · 42 行 · py_compile 通过
```

数据来源：`task.attempts`、`task.result`。

### 3.3 任务定位（新增交互）

点击侧栏任务行 → 树上的对应节点：

1. 若节点在折叠子树里 → 展开（`view.expanded.add(stageIndex)`）
2. 若当前聚焦别的工序 → 取消聚焦（`view.focus = null`）
3. `scrollIntoView({ behavior: "smooth", block: "center" })`
4. 加 `.is-flash` 类 600ms 高亮

反向（悬停树节点 → 侧栏行高亮）可选，优先级低。

## 4. 进度条公式（已实现，保留）

```
pct = (当前道序号 + 本道完成比) / 6 × 100
```

- 本道完成比 = 本道 done 任务 / 本道任务总数
- 取历史最大值，避免回环时倒退
- `clearTasks()` 时归零

---

## 5. 回放与速度（已实现，保留）

- 速度 0.1–1，存 `localStorage["nexus-speed"]`
- 回放按事件 `at` 的间隔 ÷ 速度
- 实时流：速度 < 1 时进队列，按“原始间隔 ÷ 速度”出队
- 一个旋钮同时影响节点过渡时长（`--node-dur`）
