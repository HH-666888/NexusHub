# 十五、接口与事件增量

> 原则：**只增不改**。现有 URL、字段、错误信封全部保持，前端旧逻辑不受影响。

---

## 1. 新增端点

| 方法 | 路径 | 用途 | 请求 | 响应 |
|---|---|---|---|---|
| POST | `/api/v1/runs/{id}/answers` | 门禁回答 | `{answers:[{id,value}], auto?:bool}` | `{ok:true}` |
| GET | `/api/v1/runs/{id}/gate` | 查当前门禁 | — | `{gate:{...}}` 或 `{gate:null}` |
| POST | `/api/v1/runs/{id}/rewind` | 回退到某道 | `{stage:"build"}` | `{ok:true, stage}` |
| POST | `/api/v1/runs/{id}/retry-stage` | 重跑当前道 | — | `{ok:true}` |
| GET | `/api/v1/runs/{id}/tasks` | 任务列表（可选） | — | `{tasks:[...]}` |
| POST | `/api/v1/runs/{id}/inject-failure` | 演示注入失败 | `{stage,case,kind}` | `{ok:true}` |

> 前三个接口在现有代码里已部分存在（`answers` / `gate`），只需接前端；`rewind` / `retry-stage` / `inject-failure` 为新增。

## 2. 现有端点行为变化

| 端点 | 变化 |
|---|---|
| `POST /runs` | 按 `PIPELINE` 选择 real/demo；real 不再立即返回伪造进度 |
| `GET /runs/{id}` | `total_cost_cny` 来自真实记账 |
| `GET /runs/{id}/events` | 事件数量变多；`task` 事件规范化 |
| `DELETE /runs/{id}` | 同时删工作区（已有） |
| `POST /runs/{id}/runtime` | 使用产物真实文件；端口动态 |

## 3. 事件 payload 增量

### 3.1 `phase`

```json
{"kind":"phase","phase":"awaiting","label":"等待确认","gate":{"questions":[...]}}
```

### 3.2 `task`

```json
{
  "kind": "task",
  "action": "done",
  "task": {
    "id": "task-build-7f3a1c",
    "stage": "build",
    "title": "写打卡接口",
    "kind": "code",
    "state": "done",
    "file": "api/main.py",
    "attempts": 1,
    "ms": 18400,
    "note": "POST /api/checkin",
    "result": {"files": ["api/main.py"], "lines": 42}
  }
}
```

失败时：

```json
{"kind":"task","action":"failed","task":{"state":"failed","reason":"SyntaxError: line 12","attempts":2}}
```

### 3.3 `check`

```json
{
  "kind": "check",
  "results": [
    {"name":"能创建一个习惯","pass":true,"detail":"POST /api/habits → 200"},
    {"name":"连续天数正确","pass":false,"detail":"期望 3，实际 2"}
  ],
  "summary": {"passed":1,"total":2,"failed":1}
}
```

### 3.4 `verdict`

```json
{
  "kind":"verdict",
  "layers":[
    {"layer":"db","passed":2,"total":2,"checks":[...]},
    {"layer":"api","passed":3,"total":4,"checks":[...]},
    {"layer":"ui","passed":1,"total":1,"checks":[...]}
  ],
  "passed":6,"total":7
}
```

### 3.5 `tool`

```json
{"kind":"tool","name":"write_file","args":{"path":"api/main.py"},"ok":true,"latencyMs":12}
```

## 4. SSE 帧（已实现，不变）

```
data: {"kind":"task","action":"started","task":{...},"seq":42,"at":1794221106730}\n\n
```

- `seq` 去重
- `at` 真实时间，供回放

## 5. 错误码增量

| code | HTTP | 场景 |
|---|---|---|
| `BUDGET_EXCEEDED` | 402 | 开跑前预算不足/运行中到顶 |
| `MODEL_UNAVAILABLE` | 503 | 模型连续失败 |
| `GATE_TIMEOUT` | 409 | 门禁超时自动继续（只记录，不抛） |
| `WORKSPACE_FULL` | 507 | 工作区超限 |

错误信封沿用：

```json
{"error":{"code":"BUDGET_EXCEEDED","message":"单次预算不足","hint":"去设置调高"}}
```

## 6. 前端消费清单

| 事件 | 前端动作 | 是否新增 |
|---|---|---|
| `phase(awaiting)` | 弹门禁框 | 新增 |
