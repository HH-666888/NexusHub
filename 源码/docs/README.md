## 写作纪律

- **只写能验证的东西。** 凡是没跑出数据的结论，标注为「设计目标」而不是「实测结果」。
- **主动写能力边界。** 做不到的事情明确列出来，比含糊其辞更可信。
- **竞品对比要引用对方原文。** 直接引述对方自己声明的「不做什么」，而不是转述。
