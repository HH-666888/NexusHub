# 数据库设计

## 主键与时间字段
每张业务表都要有整型自增主键，字段名统一为 id。需要排序或展示创建时间时，增加 created_at 字段，使用整数毫秒时间戳或数据库时间类型，二者只能选一种并在全表统一。

## 类型选择
文本用 TEXT 或合适长度的 VARCHAR，布尔值用 0/1 整数并加 CHECK 约束，金额用定点小数，不要用浮点数。可空字段明确写 NULL，不要把空字符串当空值。

## 索引跟查询走
只为真实查询建索引。按时间倒序列表建时间索引，按外键关联建外键索引，不要给每个字段都加索引。索引名统一为 idx_表名_字段名。

## 约束写在数据库里
必填、唯一、范围、外键能写进数据库的就不要只靠后端校验。数据库约束是最后一道防线，后端校验是用户体验，两者都要有。

## 建表脚本必须可重复执行
使用 CREATE TABLE IF NOT EXISTS，避免重复执行报错。脚本只建结构，不塞演示数据；需要初始数据时单独写种子脚本，并明确标注。
